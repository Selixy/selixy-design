# switch

Fichiers : `switch.css`.

## Rôle

- `.switch`, interrupteur rond, piste en pilule (éteint : voile 15 %, allumé : accent).

## Pourquoi

- Interrupteur : <label class="switch">Libellé <input type="checkbox"></label>. Piste en pilule et bouton rond ; éteint : voile renforcé (15 %) et bouton --text-h ; allumé : piste en accent, bouton --on-accent.
