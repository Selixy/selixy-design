# popup

Fichiers : `popup.css`.

## Rôle

- `.popup` + `__sheet` + `__action` (`--cancel`) ; derrière, voile de verre et flou, jamais de gris.

## Pourquoi

- Fenêtre surgissante, seule à passer devant l'en-tête (--z-popup). Derrière : un voile de verre (15 %) et un flou sur toute la page, jamais un fond gris. La feuille monte du bas sur téléphone et se centre au-delà de 640 px ; verre, coins légèrement arrondis (--corner).
