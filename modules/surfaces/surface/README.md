# surface

Fichiers : `surface.css`.

## Rôle

- `.surface` (bloc de verre, `--clickable`) et `.empty`.

## Pourquoi

- Surface : un bloc de contenu en verre (comme .glass) avec une marge intérieure, coins légèrement arrondis (--corner), sans bord. .surface--clickable renforce le voile au survol. .empty : message d'état vide, posé sur la page.
