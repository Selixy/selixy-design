# banner

Fichiers : `banner.css`.

## Rôle

- `.banner` (`--error`, `--warning`, `--neutral`), voile teinté de la couleur d'état, sans trait.

## Pourquoi

- Bandeau d'état : un verre dont le voile prend la couleur de l'état (--_c, à --banner-shift), texte --text-h, sans trait ni bord. .banner--error (danger), --warning (alerte), --neutral (voile ordinaire) ; sans modificateur, l'accent.
