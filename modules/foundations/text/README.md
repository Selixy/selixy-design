# text

Fichiers : `text.css`.

## Rôle

- bloc `.text` ; tailles `--display-lg`, `--display`, `--heading`, `--eyebrow`, `--body-lg`, `--body`, `--body-sm`, `--caption`, `--micro`, `--mono` ; tonalités `--strong`, `--soft`, `--dim`, `--accent`.

## Pourquoi

- Échelle typographique : un bloc .text, une taille et au plus une tonalité en modificateurs. <p class="text text--body-lg text--dim"> ; sans tonalité, le texte garde la couleur héritée.
