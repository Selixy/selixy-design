# base

Fichiers : `base.css`.

## Rôle

- Remise à zéro : `box-sizing` partout, `body` (police `--sans`, couleurs `--text` sur `--bg-0`), `main` centré à `--content-width`.

## Pourquoi

- Focus clavier : jamais de contour. Chaque composant définit son propre surlignage (voile renforcé, accent) ; ici, seuls les liens de texte passent en accent.
